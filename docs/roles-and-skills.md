## Roles and responsibilities

## Mobile Engineer (iOS/Android)

Develops, tests, and maintains native mobile applications for iOS and/or Android platforms. Collaborates with designers and backend teams to implement user interfaces and integrate with APIs, while optimizing for performance and user experience.

## Backend Engineer (API Development)

Designs, builds, and maintains server-side logic, APIs, and services that power the application. Ensures scalability, reliability, and security of the backend systems and integrates with databases and external services.

## DevOps Engineer

Automates software deployment, infrastructure provisioning, and monitoring using CI/CD pipelines and tools like Kubernetes, Docker, and Terraform. Bridges development and operations to improve system reliability, scalability, and deployment frequency.

## Security Engineer

Identifies and mitigates security vulnerabilities across applications and infrastructure. Implements security controls, conducts penetration testing, and ensures compliance with standards like PCI DSS, especially for critical services like payments.

## Database Administrator (DBA)

Manages, monitors, and optimizes database systems (e.g., PostgreSQL, Redis) to ensure performance, availability, and data integrity. Handles backups, recovery, schema changes, and troubleshooting database-related issues.

## Common skills across roles

## Cloud & Infrastructure Expertise

Proficiency with cloud platforms (AWS, GCP, Azure, or private cloud), containerization (Docker), and orchestration (Kubernetes) is fundamental for building scalable and maintainable systems.

## API Development & System Integration

Strong understanding of RESTful/gRPC APIs, microservices architecture, and message brokers (Kafka) is crucial for connecting various components of the marketplace ecosystem.

## Security Awareness & Best Practices

Knowledge of authentication/authorization (OAuth, JWT), encryption, network security, and compliance standards is essential to protect user data and financial transactions.

## Database Management & Optimization

Skills in SQL and NoSQL databases (PostgreSQL, Redis), data modeling, query optimization, and caching strategies are needed to ensure data consistency and performance.

## CI/CD & Automation

Experience with CI/CD tools (Jenkins, GitLab CI), infrastructure as code (Terraform), and automated testing frameworks enables rapid and reliable software delivery.
